# Gerador de Crachá Virtual em JavaScript

## 📌 Objetivo do Projeto
Este projeto foi desenvolvido como um exercício prático de JavaScript e Git/GitHub para simular a criação de um crachá virtual. 

O sistema solicita informações do utilizador, processa os dados recebidos e exibe as informações formatadas na consola do navegador.

## 🛠️ Funcionalidades
- **Coleta de Dados:** Utiliza `prompt()` para recolher o nome, sobrenome e ano de nascimento, e `confirm()` para verificar o estatuto de aluno ativo.
- **Processamento de Dados:**
  - Converte o ano de nascimento para um tipo numérico (`Number()`).
  - Calcula a idade estimada do utilizador com base no ano atual.
  - Formata o sobrenome para letras maiúsculas (`.toUpperCase()`).
  - Conta o número de carateres do primeiro nome (`.length`).
- **Exibição:** Apresenta o crachá formatado na consola (`console.log()`).
